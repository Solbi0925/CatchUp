Catchup

## 한 줄 소개

Google Calendar를 사용하는 대학생의 강의계획서, LMS 공지, 과제, 시험, 개인 일정을 AI가 정리해 지금부터 실행 가능한 7일 계획과 날짜별 할 일을 추천해주는 웹앱 기반 학업 일정 매니저입니다.

## 해결하려는 문제

대학생은 학업 일정과 개인 일정이 여러 채널에 흩어져 있어 중요한 마감일을 놓치거나 무엇부터 해야 할지 판단하기 어렵습니다.

## 타깃 사용자

- Google Calendar를 사용하는 여러 과목 수강 대학생
- LMS 공지와 강의계획서를 자주 확인해야 하는 학생
- 과제, 시험, 개인 일정을 함께 관리해야 하는 학생
- 일정 관리가 어렵거나 마감 직전에 몰아서 하는 학생

## 1차 MVP 범위

- 강의계획서, LMS 공지, 과제 명세서 등 학업 자료 업로드
- PDF와 이미지 파일 형식 지원
- AI 기반 과제명, 마감일, 시험일, 제출 방식, 중요 일정 추출
- 추출된 정보 확인 및 수정
- Google Calendar와 학업 일정 기반 7일 학습 계획 생성
- CatchUp 안에서 개인 일정 직접 추가 및 수정
- 사용자가 원하는 날짜에 계획 생성을 요청하고 요청일을 Day 1로 하여 7일 계획 생성
- 계획 기간(`planStartDate ~ planStartDate + 6일`)과 Today의 월~일 Calendar Week를 분리
- Today에서 실제 오늘이 포함된 월~일 주차를 기본 표시하고 이전 주·다음 주 이동 지원
- 현재 7일 Plan 범위 밖 날짜의 날짜 원(circle)을 회색으로 표시
- 계획 생성 시 자연어 요구사항 입력
- 현재 상태 기준 향후 약 4주 일정을 참고해 현재부터 7일 계획 생성
- 완료 체크하지 않은 미완료 과제를 삭제하지 않고 다음 계획 생성 시 입력에 포함해 재배치
- AI Mate를 통한 일일/주간 계획 조정 요청
- AI Mate 계획 조정 요청은 하루에 최대 10번만 가능
- 추천 계획에 대한 간단한 근거 설명
- Month 날짜 칸에 일정 제목 표시
- 6색 제한 팔레트로 과목별·개인 일정 카테고리 구분 및 카테고리 전체 색상 변경

## 제품 결정사항

- Plan은 사용자가 요청한 날짜부터 정확히 7일이다. 자동 주간 생성은 사용하지 않는다.
- Today는 Plan과 독립적으로 월요일~일요일 Calendar Week를 표시한다. 진입 시 실제 오늘이 포함된 주차를 기본으로 보여주며, 이전 주·다음 주 이동이 가능하다.
- 계획 생성 시 AI는 요청일 기준 향후 약 4주의 일정, 마감일, 예상 소요시간, 난이도, 중요도·우선순위, 기존 미완료 과제를 참고한다.
- 서비스 컨셉명은 아직 논의 중이다. 문서에서는 어떤 시점에 돌아와도 현재 상태와 향후 일정을 바탕으로 실행 가능한 계획을 구성한다는 가치만 설명한다.
